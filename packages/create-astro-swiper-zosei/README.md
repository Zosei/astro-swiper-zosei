# create-astro-swiper-zosei

> Interactive CLI to scaffold Astro Swiper Zosei and AI Agent configuration.

## Usage

```bash
# With npm
npm create astro-swiper-zosei@latest

# With pnpm
pnpm create astro-swiper-zosei@latest

# With yarn
yarn create astro-swiper-zosei

# With bun
bun create astro-swiper-zosei
```

# Security Policy

## Supported Versions

Security fixes and dependency updates are actively maintained for the latest minor release of `astro-swiper-zosei`:

| Version | Supported          |
| ------- | ------------------ |
| 0.17.x  | :white_check_mark: |
| 0.16.x  | :x:                |
| < 0.16  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `astro-swiper-zosei`, please **do not** open a public issue.

Instead, report it privately via GitHub Security Advisories:

- https://github.com/Zosei/astro-swiper-zosei/security/advisories/new

Please include:
- Affected version (`astro-swiper-zosei`, `astro`, and `swiper` versions)
- Minimal reproduction steps or proof of concept
- Potential impact

You can expect an initial response within 72 hours and coordinated disclosure once a fix is published.
